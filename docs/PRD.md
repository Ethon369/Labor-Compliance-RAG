# PRD：劳动争议智能合规助手 v1

## 一句话
基于中国劳动法律体系的 RAG 问答系统，回答必须附带法条原文引用，支持经济补偿金等计算工具。

## 数据范围（v1 锁定）
- 《劳动法》《劳动合同法》全文（条款级切分）
- 最高人民法院劳动争议司法解释（一）（二）
- 本地裁判文书 50–200 篇（中国裁判文书网公开数据）
- 不做：地方性法规对比、多轮案情推理、判决预测（v2 再说）

## 核心流程
用户提问 → 查询改写 → 混合检索（向量+BM25）→ Rerank → 引用核验
→ 生成带法条编号的回答 / 触发计算工具

## 功能与验收标准
| 功能 | 验收标准 |
|---|---|
| 法条入库 | 条款级切分，含法名/条号/条文本，可按条号精确检索 |
| 混合检索 | 同一问题下混合检索召回率 ≥ 纯向量检索（用评测集证明） |
| 引用回答 | 每个结论标注法条出处；检索结果不支持时明确拒答 |
| 补偿金计算器 | 工作年限+月薪输入 → N×月工资输出，LLM 判断何时调用 |
| 流式接口 | SSE 推流，前端逐字显示 |
| 评测 | 50 条评测集，输出各策略准确率对比表 |
| 部署 | docker compose up 一键起全套 |

## 非目标
多用户、权限系统、前端页面美化
